
# Weather Analyzer 

## 📌 Overview
Weather Analyzer is a simple Python program that allows users to:
- Enter their city name  
- Enter the current temperature  
- Receive a personalized weather description and suggestion  

This project helps users quickly understand the weather condition based on the temperature they input.

---

## ✨ Features
- Input city name  
- Enter today's temperature  
- Displays weather description (hot / warm / cold / very cold)  
- Personalized suggestions  
- Simple and user-friendly CLI interface  

---

## 🛠 Technologies Used
- Python 3  
- VS Code  
- Git & GitHub
